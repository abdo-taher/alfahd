## KPI Framework Overview and Measurement Philosophy

Al-Fahad's SEO program is an investment in long-term lead generation, not a short-term traffic campaign. The KPI framework reflects this by measuring:

1. **Leading indicators** (activity metrics that predict future performance): pages published, links acquired, reviews collected
2. **Lagging indicators** (outcome metrics that reflect past performance): organic traffic, rankings, RFQ volume
3. **Business metrics** (what ultimately matters): qualified leads, RFQ to project conversion, organic revenue attribution

**Philosophy:** KPIs are reviewed monthly, but business decisions are made quarterly. Week-to-week fluctuations in rankings are normal and expected; 90-day trends are the actionable signal.

**Measurement tools:**
- **GSC** — Google Search Console: impressions, clicks, average position
- **GA4** — Google Analytics 4: sessions, conversions, engagement
- **Ahrefs** — Domain authority, keyword rankings, backlinks
- **BrightLocal** — Local Pack rankings, GBP performance, citation tracking
- **Hotjar/Microsoft Clarity** — User behavior, form abandonment, heatmaps

### Lead Generation Target Justification

These RFQ targets are based on:
- Saudi B2B construction organic conversion rate benchmarks (1.5–3% visitor-to-inquiry for commercial intent pages)
- Al-Fahad's average project value: SAR 200K–3M
- Progressive traffic growth from Phase roadmap

**Monthly organic revenue potential at Month 12:**
- 60–120 RFQs/month × 70% qualification = 42–84 qualified leads
- 42–84 × 15% close rate = 6–13 new projects/month from organic
- 6–13 × SAR 400K avg. project value = SAR 2.4M–5.2M/month in organic revenue

## Alert Thresholds (Conditions Triggering Immediate Investigation)

| Condition | Threshold | Immediate Action |
|---|---|---|
| **Traffic drop** | >20% month-over-month organic session decline | Check GSC for manual penalties; review Google Search Status for algorithm updates; audit for technical issues (robots.txt, noindex errors) |
| **P1 keyword rank drop** | Any P1 keyword drops >10 positions in a single week | Investigate: new competitor content, algorithm update, on-page issue, manual penalty |
| **GBP suspension** | Google Business Profile suspended | Immediately follow GBP reinstatement process; contact Google Business Profile support |
| **GSC coverage errors** | Indexed pages drop >10% with no corresponding page deletion | Crawl site immediately; check for robots.txt change, noindex deployment error, or server issue |
| **Core Web Vitals regression** | LCP exceeds 4s or CLS exceeds 0.25 on any key commercial page | Immediate Dev investigation; check for new third-party script, image loading regression, font load change |
| **RFQ conversion drop** | >30% drop in RFQ form submissions with no traffic change | Check RFQ form for technical errors; review form abandonment in Clarity/Hotjar |
| **Negative SEO attack** | >50 new toxic/spammy referring domains in a single month | Run Ahrefs backlink audit; disavow toxic links via GSC if needed |
| **Competitor major content launch** | Competitor publishes 10+ new service or comparison pages targeting P1 keywords | Accelerate content production in that keyword space; refresh and expand competing pages |
| **Review bombing** | 3+ negative reviews in a 7-day period | Alert management; respond professionally to each review; flag for platform review if suspicious |
